## libcint

> fortran的矩阵存储顺序和c是不一样的，所以矩阵atm和bas行列要对调

关键是确定好atm,bas,env

- `buf`，real(8)，存储最终的积分结果，单电子积分为二维矩阵，双电子积分为四维矩阵
- `shls`，int，存储电子积分开始的指标，需要在循环中由`CINTgto_cart`等动态确定，单电子积分长度为2，双电子积分长度为4
- `atm`，int，[6,natm]，存储原子信息，每一个原子包含6个整数信息
  1. 核电荷数
  2. 存储在env中的坐标的起始索引,坐标为(x,y,z)，x在env的索引位置
  3. 核模型，设为0
  4. 核电荷分布参数索引，设为0
  5. unused，设为0
  6. unused，设为0
- `natm`，int，原子的数量
- `bas`，int，[8,nbas]，存储基组信息，每一个基组包含8个整数信息
  1. 所属原子的索引，0-based
  2. 角动量
  3. 原始gto的数量，比如`3to-3g`的1s为3
  4. 收缩gto的数量，据我目前所见都是1，一个α结合一个c
  5. kappa for prinor GTO，设为0
  6. env中，指数的索引，0-based
  7. env中，系数的索引，0-based
  8. unused，设为0
- `nbas`，int，基组的数量
- `env`，real(8)，很长的一维向量，存储原子坐标，高斯指数和收缩系数，有用的信息都存储在这
